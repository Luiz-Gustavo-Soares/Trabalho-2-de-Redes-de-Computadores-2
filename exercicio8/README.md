O tráfego ICMP gerado na rede local registrou perfeitamente as requisições "Echo (ping) request" enviadas para o endereço IP do gateway (192.168.1.1) e as suas correspondentes respostas "Echo (ping) reply". Ao inspecionar os detalhes da camada ICMP nos pacotes de resposta, foi possível extrair e validar o tempo de ida e volta (RTT), que se demonstrou estável e com baixa latência.
