A captura de resolução de nomes evidenciou o envio de pacotes "Standard query" solicitando os registros do tipo A (IPv4) e AAAA (IPv6) para o domínio www.google.com. O servidor DNS consultado (8.8.8.8) processou o pedido e retornou com sucesso a "Standard query response", contendo na seção "Answers" o mapeamento correto do domínio para os seus respectivos endereços IP.
