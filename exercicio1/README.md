## Execucao do server 
```
$ python3 exercicio1/server_tcp.py

  -h, --help            show this help message and exit
  -p PORT, --port PORT  porta de execucao do servidor
```


## Execucao do client 
```
$ python3 exercicio1/client_tcp.py 

options
  -h, --help            show this help message and exit
  -p PORT, --port PORT  porta de cenexão no servidor
  -s HOST, --host HOST  host de cenexão no servidor
```
